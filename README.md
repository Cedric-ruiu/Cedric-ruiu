Twenty years of web development, now on my own from Séné, on the Gulf of Morbihan. I design, build and ship sites end to end, and I cover in one place the three things most projects split across three vendors.

**Build** — Custom sites and web apps: content model, interface, code, deployment. Static-first when it fits, a framework when it earns its place.

**Rank** — Full-site technical SEO audits, run through a crawler and reporting pipeline I wrote myself. Findings come out prioritised, and when I have the codebase, applied rather than just listed.

**Speed** — Core Web Vitals, payload budgets, render path. Fewer bytes and fewer requests: better for users, better for search, and lighter on the servers and devices that carry it.

## How I work

- **Static-first.** If a page can be a file, it should be a file. Nothing to patch, nothing to keep alive.
- **No lock-in.** Code, content, images and domain belong to the client. Nothing sits behind a subscription or a tool they have no key to.
- **One person.** The one who understands the brief is the one who writes the code and pushes it live.
- **Performance and accessibility up front.** Not a cleanup pass three weeks after launch.
- **Boring where it counts.** Dependencies are a liability. I add one when it pays for itself.
